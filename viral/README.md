# Viral package — CADBench launch

Everything you need to ship the launch in one folder. Pick one theme, copy
the post body, post it, then drop the link in your follow-up reply.

```
viral/
  README.md           ← this file
  themes.md           ← 5 angles + which audience each one targets
  playbook.md         ← post timing, follow-up templates, do/don't
  x/                  ← Twitter/X variants (≤ 280 chars, all measured)
    01-flange-finding.md
    02-numbers-led.md
    03-tech-flex.md
    04-builder-personal.md
    05-thread-starter.md
  hn/                 ← Hacker News (≤ 80 char title)
    title.md
    submission-comment.md
  assets.md           ← which screenshot from viral-prep/ goes with what
```

## TL;DR

- **Best post-once-and-walk-away X**: `x/01-flange-finding.md`
- **Best HN title**: `hn/title.md` (top option)
- **Best image to attach to X**: `viral-prep/01-leaderboard.png`
- **Best image for HN**: don't attach an image — use the comment-link
  pattern, see `hn/submission-comment.md`

The product side is done. Don't tweak the post — pick one and ship.
